# ANIMATRIX

Offline-first Android animation editor foundation.

## Current build
- Native Android project
- Offline project storage
- Autosave
- Frame-based animation model
- Layers
- Drawing canvas and pencil strokes
- Frame creation and timeline
- Undo / redo
- JSON project format
- GitHub Actions APK build

## Build
`./gradlew :app:assembleDebug`

Reference APKs are used only for capability/workflow research. Do not copy proprietary source, assets, branding, or exact screens.
